Steve Backup — обработка данных

Область документа

Этот документ описывает только приложение Steve Backup для загрузки зашифрованных резервных копий. Правила личного диалога с ботом Стивом согласуются отдельно.

Посещение информационного сайта

Информационные страницы размещены на GitHub Pages. GitHub регистрирует IP-адреса посетителей для безопасности; применяется политика конфиденциальности GitHub. На самих страницах нет форм сбора данных, аналитических скриптов и рекламных инструментов.

Какие данные обрабатываются

Приложение обрабатывает зашифрованные архивы, идентификаторы своих файлов и папки в Google Drive, даты, размеры и контрольные суммы. Для автоматического доступа используются данные авторизации Google, хранящиеся с ограничением доступа.

Для чего используются данные

Только для создания резервных копий, загрузки, проверки целостности, восстановления и управления сроком хранения. Данные не продаются и не используются для рекламы.

Доступ и передача

Зашифрованные архивы передаются в Google Drive владельца. У приложения есть разрешение drive.file на созданные или явно разрешённые ему файлы. Для загрузки не требуется ключ расшифровки.

Хранение

Выбранное правило — последние 7 отдельных дневных снимков и 4 недельных снимка, с возможным совпадением копий. Лишние архивы удаляются только после успешной загрузки и проверки новой копии. При сбое старая проверенная копия сохраняется.

Управление разрешениями и удаление

Владелец может отозвать доступ в настройках своего Google-аккаунта. Это остановит новые операции приложения, но само по себе не удалит ранее созданные архивы. Запросы на удаление и удаление сообщений Telegram обрабатываются отдельно.

Вопросы и изменения

Адрес поддержки указан в окне авторизации Google. При изменении способов обработки данных этот документ должен быть обновлён до применения изменений.
