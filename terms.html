Steve Backup — условия использования

Назначение

Steve Backup предназначен для личной автоматизации резервного копирования владельца. Информационный сайт не принимает файлы посетителей и не предлагает платных услуг.

Условия доступа

Подключение выполняется через авторизацию Google. Владелец определяет, какие разрешения предоставить, и может отозвать их в своём Google-аккаунте.

Восстановление

Для восстановления нужен отдельный ключ расшифровки. Регулярная проверка копий и пробное восстановление нужны для проверки сохранности данных.

Границы резервирования

Наличие копий не гарантирует отсутствие потери данных между снимками. Публикация информационного сайта сама по себе не подтверждает полную эксплуатационную готовность бота.

Текущий этап

Приложение проходит проверку на учебных данных. Переход к реальным данным и подключение второго участника согласуются отдельно.

Обновлено 28 октября 2026 года. Адрес поддержки указан в окне авторизации Google.
